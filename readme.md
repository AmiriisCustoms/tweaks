## Tweaks

### RelayBridge4iOS
Use a spare jailbroken iPhone as a Continuity relay device, like an iPad or Mac: send and receive SMS and phone calls through your main iPhone, with iMessage and FaceTime working normally. [Package page](https://amiriiscustoms.github.io/tweaks/depictions/relaybridge.html)

### Silenced Home Button
Mutes the Touch ID home-button click haptic on iPhone 7, 7 Plus, 8, 8 Plus and SE (2nd/3rd gen) — for a rattly or damaged Taptic Engine. The button still works and Touch ID is unaffected. [Package page](https://amiriiscustoms.github.io/tweaks/depictions/silencedhomebutton.html)
