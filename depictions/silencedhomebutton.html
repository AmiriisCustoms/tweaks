Silenced Home Button

by Amirii's Customs™ · version 1.0.2

Mutes the Touch ID home-button click haptic. For an iPhone with a solid-state home button whose Taptic Engine rattles, buzzes or is damaged — the button still works and Touch ID is unaffected, only the buzz is removed.

How to use

  1. Install, then respring / userspace reboot so it loads.
  2. Settings → Silenced Home Button → On.
  3. Tap the blue Respring button (top right) to apply.

Off by default — installing changes nothing until you switch it on. Turn it off and respring to bring the click back.

How it works

The home-button click is a Taptic actuation that backboardd loads from a haptic config. This tweak sets that click's gain to zero, so the button keeps a configured haptic (iOS never disables it) but the engine actuates at zero amplitude — silent. Nothing else is touched.

Compatibility

  • Solid-state home-button devices: iPhone 7, 7 Plus, 8, 8 Plus, SE 2nd gen, SE 3rd gen.
  • Tested: iPhone 8 Plus, iOS 16.7, palera1n.
  • Rootless (iOS 15+) and rootful (iOS 10-14) packages, arm64 + arm64e.
  • Other versions are expected to work but untested — please report.
